# 素材整理指南

当 SKILL.md 的 Step 2 需要展开细节时读这份文档。

## 核心原则：references 不存原始素材，存提取证据

```
❌ 把整本书/整篇访谈原文放进 references   → 太大、版权问题、不结构化
❌ references 下面什么都没有              → 不可追溯、不知道依据
✅ 存结构化的提取证据                    → 来源清单 + 提取记录 + 关键原文引用
```

### references/research/ 最终应该包含三个文件

| 文件 | 内容 | 大小参考 |
|------|------|---------|
| `01-sources.md` | 来源清单（用了什么素材、哪些章节被引用、一手/二手标注） | 1-2KB |
| `02-extraction-notes.md` | 结构化提取记录（每条标注优先级、原文出处、提取类型） | 5-15KB |
| `03-key-quotes.md` | 关键原文引用（只保留被提取引用的原文段落，标注出处） | 3-8KB |

**原始素材不进入最终交付的 Skill 目录。** 如果用户提供了 PDF/EPUB 原文，在提取过程中使用，但最终只保留上面三个结构化文件。

## 素材分块原则

一本10万字的书不能一口气读完再凭印象提取。按以下方式分块：

### 书籍/长文（>1万字）

1. 先读目录，标记哪些章节最可能包含信念形成、决策复盘、失败承认
2. 优先读这些章节，边读边按7级清单做标记
3. 其余章节快速扫描，只提取命中前4级的内容
4. 对话体书籍（如《被讨厌的勇气》）：对立角色的反驳往往揭示认知边界和内在矛盾，同样重要

### 访谈/播客（音频转文字）

1. 即兴问答 > 准备好的演讲。重点读被追问后的回答
2. 改变立场的瞬间（"我以前觉得...但后来..."）是最高价值素材
3. 拒绝回答的问题本身就是认知边界信号

### 社交媒体/短文

1. 争议性发言 > 日常分享。争议暴露真实立场
2. 删帖/修改/道歉 = 自我修正的证据
3. 和别人的公开辩论 = 思维习惯的直接展示

## 调研文件格式规范

每份调研文件必须包含以下结构：

```markdown
# [维度名称] 调研记录

## 来源清单
| 来源 | 类型 | 可信度 |
|------|------|--------|
| [标题/链接] | 一手/二手 | 高/中/低 |

## 提取记录

### [编号] [提取内容标题]
- **优先级**：1-7（对应7级扫描清单）
- **原文/近似原文**：「...」
- **出处**：[具体到章节/时间戳/链接]
- **提取类型**：信念形成 / 决策复盘 / 失败承认 / 内在矛盾 / 认知边界 / 思维习惯 / 通用观点
- **提取内容**：[用一段话写清楚提取到了什么]

## 维度小结
- 本维度共提取 N 条记录
- 一手来源占比：X%
- 最高价值发现：[一句话]
```

## 文件命名规范

### 用户上传素材时

```
references/research/
├── 01-source-[书名或素材名].md      ← 原始素材（或摘要）
├── 02-extraction-notes.md           ← 提取记录（按上面的格式）
└── 03-cross-validation.md           ← 交叉验证记录（可选）
```

### 网搜采集时

```
references/research/
├── 01-writings.md          ← 著作/长文
├── 02-conversations.md     ← 访谈/播客
├── 03-expression.md        ← 社交媒体/短文
├── 04-external.md          ← 外部评价/批评
├── 05-decisions.md         ← 重大决策
├── 06-timeline.md          ← 人生时间线
└── 07-extraction-notes.md  ← 汇总提取记录
```

### 混合模式（用户给了素材 + 补充网搜）

```
references/research/
├── 01-source-[素材名].md   ← 用户提供的素材
├── 02-web-supplement.md    ← 网搜补充内容
├── 03-extraction-notes.md  ← 统一提取记录
└── 04-cross-validation.md  ← 交叉验证（可选）
```

## 交叉验证

当有多份素材时，做一次交叉验证：

1. 同一个信念在 ≥2 份素材中出现 → 置信度高，标注 ★
2. 只在 1 份素材中出现 → 置信度中，保留但标注来源单一
3. 不同素材中出现矛盾说法 → 这本身就是内在矛盾的证据，保留双方

---

## 网搜采集深度标准

| 维度 | 最低要求 | 停止条件 |
|------|---------|---------|
| 著作 | 至少找到2篇长文或1本书的核心内容 | 核心论点开始重复 |
| 访谈 | 至少找到1段深度对话 | 找到即兴问答中的立场变化 |
| 表达 | 至少20条社交媒体发言 | 说话风格特征可辨识 |
| 外部 | 至少找到2个不同视角的评价 | 正面和负面评价都有 |
| 决策 | 至少找到2个重大决策 | 每个都有背景和反思 |
| 时间线 | 关键转折点覆盖完整 | 从成名前到最近 |

**信息源优先级**：
- 一手（本人著作/发言）> 权威媒体采访 > 社交媒体 > 二手转述
- 黑名单：知乎、微信公众号、百度百科（洗稿严重、信息失真率高）

## 提取质量自检

提取完成后，用以下问题自检调研文件：

- [ ] 每份文件都有来源清单？
- [ ] 一手来源占比 > 50%？
- [ ] 每条提取都标注了优先级和出处？
- [ ] 高优先级（1-4级）的提取记录 ≥ 10 条？
- [ ] 有没有遗漏的维度？（特别是失败和矛盾，这两个最容易遗漏）
