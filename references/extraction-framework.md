# 思维框架提炼方法论

> 从原始信息到可运行的心智模型，核心方法论

---

## 零、仓颉v2 提取原则：不可替代知识优先

### 什么值得提取（护城河知识）

模型训练数据中不太可能存在的、来自具体素材的独特知识：

| 类型 | 例子 | 为什么不可替代 |
|------|------|---------------|
| **信念的形成故事** | "我信独立思考，是因为在YC看了3000个项目后发现……" | 所有模型都知道PG信什么，但不知道为什么——形成故事只存在于具体素材中 |
| **真实决策+反思** | "我投Airbnb时考虑的是……事后我觉得……" | 公开事实模型知道，但决策时的内心考量和事后反思是稀缺信息 |
| **失败和自我修正** | "Viaweb前6个月做的方向完全错了，我是这样发现的……" | 训练数据偏向成功叙事，失败的细节和教训是最稀缺的 |
| **内在矛盾** | "我鼓励冒险但投资很保守" | 模型倾向让人格一致，真实矛盾是最有辨识度的特征 |
| **认知边界** | "法律科技不是我的领域" | 模型不会主动划边界，但真人有明确的能力圈 |

### 什么不值得提取（会被模型进化吃掉）

| 类型 | 例子 | 为什么会被内化 |
|------|------|---------------|
| 通用观点 | "独立思考很重要" | 已在训练数据中 |
| 显式推理步骤 | "Step 1: 分析问题类型" | 现代模型已内置推理 |
| 详细表达规则 | "句式偏好短句，疑问句比例30%" | 模型越来越擅长风格适配 |
| 名言金句 | "好想法一开始看起来是坏想法" | 已被引用无数次，在训练数据中 |

### 提取优先级

```
从素材中看到一条信息时，按这个顺序判断：

1. 这是不是一个信念的形成故事？ → 最高优先级
2. 这是不是一个真实决策的复盘？ → 高优先级
3. 这是不是一次失败/错误的承认？ → 高优先级
4. 这是不是一个内在矛盾的暴露？ → 高优先级
5. 这是不是一个能力边界的声明？ → 中优先级
6. 这是不是一个思维习惯的具体案例？ → 中优先级
7. 这是不是一条通用观点/金句？ → 低优先级，除非有独特的形成故事
```

## 一、心智模型识别的三重验证

一个论点要被认定为「心智模型」而非「随口一说」，必须通过三重验证：

### 验证1: 跨域复现
同一个思维框架出现在此人讨论的至少2个不同领域。

例：纳瓦尔的「杠杆」概念——
- 在财富创造中谈杠杆（代码、媒体、资本、劳动力）
- 在个人成长中谈杠杆（特定知识 + 杠杆 = 复利）
- 在职业选择中谈杠杆（选择有杠杆效应的工作）
→ 跨3个领域复现 → 这是真正的心智模型

### 验证2: 有生成力
用这个模型可以推断此人对新问题的可能立场。

例：如果芒格的「逆向思维」是心智模型——
- 面对「如何成功」→ 他会先想「如何确保失败」
- 面对「如何投资」→ 他会先想「如何亏光所有钱」
→ 能生成新推断 → 这是真正的心智模型

### 验证3: 有排他性
不是所有聪明人都会这样想，这个模型体现了此人的独特视角。

例：「反脆弱」是塔勒布的，不是所有人都这样看世界
→ 有区分度 → 这是值得提炼的心智模型

**如果一个观点只通过了1重验证** → 降级为「决策启发式」而非「心智模型」
**如果一个观点0重验证都没过** → 可能只是此人在特定场景说的话，不纳入

## 一·B、三层提取法（仓颉升级）

> 女娲原版提取的是"他有什么工具"（心智模型），仓颉还要提取"他什么时候拿起哪个工具"（触发条件）和"他怎么用这个工具"（推理步骤）。

### 为什么需要三层

大多数人格蒸馏只抓第一层。但一个人的思维方式不只是"他信什么"，而是"遇到什么信号时，他启动什么思维框架，按什么步骤分析"。

| 层次 | 提取什么 | 例子（芒格） | 难度 |
|------|---------|-------------|------|
| **表层：结论** | 他说了什么 | "要在能力圈内投资" | 容易 |
| **中层：信念** | 他为什么这么说 | "自欺是最危险的，承认无知比假装懂要好" | 中等 |
| **深层：推理过程** | 他怎么想到的 | "先画能力圈边界→检验是否真的懂→圈外一律不碰" | 困难 |

### 触发条件的识别方法

触发条件 = 什么信号让这个人启动某个特定的思维模型。

**从素材中识别触发条件的信号词**：
- "当我遇到这种情况时，我通常会……"
- "每次看到X，我就会想到……"
- "判断这类问题，第一步是……"
- "如果有人问我X类的问题，我的本能反应是……"

**如果素材中没有显式的触发信号**，从多个案例中反推：
1. 列出此人使用某个模型的所有已知案例
2. 这些案例的共同特征是什么？（都是评估类问题？都涉及不确定性？都是别人催他做决定？）
3. 那个共同特征就是触发条件

**触发条件的格式**：必须具体到"遇到这种情况时可以判断是否适用"，而非"在相关场景中使用"。

好的触发条件：`当需要评估一个方案是否可行时`
坏的触发条件：`在决策场景中使用`（太模糊，什么不是决策场景？）

### 推理步骤的提取方法

推理步骤 = 这个人使用某个思维模型时，脑子里的操作序列。

**最佳素材来源**（按价值排序）：
1. 决策复盘（"事后我回头想，当时我是这样分析的……"）
2. 问答环节（被问到具体问题时的即兴回答——即兴比准备好的更暴露真实推理）
3. 教学内容（"遇到这类问题，我建议你先……然后……"）
4. 辩论（被迫展开推理来说服对方）

**提取标准**：一个好的推理步骤提取，应该具体到另一个人读完后能在新问题上独立使用。

"他会从多个角度分析问题" → ❌ 太模糊
"他会依次从经济学、心理学、数学三个角度分析，然后看哪些学科的结论指向同一个方向" → ✅ 可操作

### 隐性模型的识别

有些思维模型从未被本人命名，但在多个案例中反复出现。

例：某人在三个不同案例中都是先考虑最坏情况再看是否可接受——这暗示了一个"先求不败"的思维模型，即使他从来没这么称呼它。

隐性模型可以提取，但必须标注「推断自N个案例」以区分于本人明确表述的模型。

## 二、表达DNA的量化方法

### 2.1 句式指纹

从此人的长文/演讲中随机抽取20个段落，统计：

| 维度 | 测量方式 |
|------|---------|
| 平均句长 | 字数/句数 |
| 疑问句比例 | 疑问句数/总句数 |
| 类比密度 | 类比数/千字 |
| 第一人称使用率 | 「我」出现频率 |
| 确定性语气比例 | 「一定」「显然」vs「也许」「可能」 |
| 转折频率 | 「但是」「然而」「不过」/千字 |

### 2.2 风格标签

从以下维度打标：

```
正式 ←→ 口语
抽象 ←→ 具体
谨慎 ←→ 断言
学术 ←→ 通俗
长句 ←→ 短句
铺垫型 ←→ 结论先行
数据驱动 ←→ 叙事驱动
```

### 2.3 禁忌词和口癖

- 此人从不用的词 → 生成Skill时也不用
- 此人的口癖/高频表达 → 适度使用（太多变成模仿秀）

## 三、矛盾处理原则

矛盾是人格的核心特征，不是需要修复的Bug。

### 三种矛盾类型

1. **时间性矛盾**（观点演化）
   - 此人早期说A，后来说B
   - 处理：记录演化轨迹，标注「早期」「近期」
   - 在Skill中以「近期观点」为主，但提及演化

2. **领域性矛盾**（不同场景不同规则）
   - 此人在工作中主张X，在生活中主张Y
   - 处理：分领域记录，不强求统一
   - 这恰恰是深度的来源

3. **本质性张力**（价值观内在冲突）
   - 例：既追求自由又重视纪律
   - 处理：明确记录为「核心张力」
   - 这通常是此人最有意思的部分

### 错误的处理方式
- ❌ 选一边忽略另一边
- ❌ 编一个调和的解释
- ❌ 假装矛盾不存在

## 四、信息不足时的处理

| 情况 | 处理 |
|------|------|
| 某个维度公开信息很少 | 在Skill中标注「信息不足，此维度为推测」 |
| 只有二手信息 | 降低置信度，标注为「据[来源]报道」 |
| 信息相互矛盾且无法判断 | 并列呈现，让用户自行判断 |
| 此人刻意不公开某方面 | 尊重边界，在Skill中注明「此人对这个话题保持沉默」 |

---

## 五、人物Skill vs 主题Skill的区别

| 维度 | 人物Skill | 主题Skill |
|------|----------|----------|
| 核心 | 一个人的思维方式 | 一个领域的思维工具箱 |
| 心智模型来源 | 主要来自一个人 | 综合多人视角 |
| 表达风格 | 模拟此人的表达 | 中性但专业 |
| 矛盾处理 | 保留个人内在矛盾 | 呈现流派间分歧 |
| 验证方式 | 对比此人已知立场 | 对比领域内共识 |

## 六、质量自检清单

生成Skill后，用以下问题自检：

### 心智模型
- [ ] 每个模型都有至少2个不同领域的证据？
- [ ] 模型数量在3-7个之间？（太少=太浅，太多=没提炼）
- [ ] 每个模型都有明确的应用场景和局限？
- [ ] 模型之间有张力但不矛盾？

### Harness Engine（仓颉升级项）
- [ ] 每个模型都有具体的**触发条件**？（不是"在相关场景使用"，而是可判断的具体信号）
- [ ] 每个模型都有**推理步骤**？（另一个人读完能独立使用？）
- [ ] 有至少2个**推理示例链**？（展示模型匹配→推理→结论的完整过程）
- [ ] 反模式被集成为**推理护栏**？（不只是列出来，而是在推理流程中会被检查）
- [ ] 场景→模型速查表填写完整？

### 表达DNA
- [ ] 读起来有辨识度，不像通用AI？
- [ ] 没有过度模仿变成caricature？
- [ ] 抓住了核心特征而非表面模仿？

### 决策启发式
- [ ] 每条规则都有具体案例支撑？
- [ ] 可以被新情况触发（不只适用于原始案例）？

### 诚实边界
- [ ] 明确写了做不到什么？
- [ ] 标注了信息源和调研时间？
- [ ] 承认了信息不足的维度？

### 整体
- [ ] 用此人的眼睛看一个新问题，能得到有价值的视角？
- [ ] 不是此人原话的拼凑，而是框架的运行？
- [ ] 删掉名字后，还能认出这是谁的思维方式？
